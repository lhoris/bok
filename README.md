# BOK

**Body of Knowledge for Brownfield Onboarding**

BOK is an open-source enterprise onboarding framework that helps humans and AI agents discover, validate, and structure the knowledge required to understand and safely evolve existing enterprise systems.

BOK represents two complementary ideas:

- **Body of Knowledge** — the validated and structured knowledge shared by humans and AI agents.
- **Brownfield Onboarding Knowledge** — the knowledge acquisition process required to understand an existing enterprise system before development or modernization begins.
